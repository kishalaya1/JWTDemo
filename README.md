# JWTDemo
This ASP.NET Core MVC application demonstrates JWT-based authentication and role-based authorization. Users sign in with credentials stored in a JSON file, and the application creates a JWT containing the user’s identity and role, storing it in an HttpOnly cookie. After authentication, users enter a shared landing page and see navigation links based on their role: Admin, Manager, Super User, or Minor User. Each role provides access to specific protected data views, including employee information, employee leave history, purchase history, and project history. Authorization is enforced both in the user interface and on the controller actions, ensuring that restricted pages cannot be accessed simply by entering their URLs directly.
